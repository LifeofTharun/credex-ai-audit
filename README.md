# AI Spend Audit

A Next.js application to audit AI tool expenditures and find optimal pricing.

## 5 Key Decisions
1. **App Router**: Using Next.js 14+ App Router for modern server-side rendering.
2. **Tailwind CSS**: Rapid UI development with utility-first styling.
3. **Audit Engine Logic**: Rule-based engine in `src/lib/audit-engine.ts`.
4. **Supabase**: Backend-as-a-service for user data and audit logs.
5. **Multi-Step Form**: Improved UX for capturing complex tool usage data.
